# GNS3 Server Setup на Ubuntu для Windows-клиента

Этот репозиторий содержит инструкцию и скрипт для быстрого развертывания сервера GNS3 на Ubuntu Server и подключения к нему с Windows-клиента.

Цель проекта: иметь под рукой готовое решение для работы с виртуальной сетью. 
Также данная развертка позволяет работать в режиме многопользовательского подключения

UDP: Версия GNS3 должна быть одинаковой на сервере и на клиентских ПК. В таком варианте сессии будут работать стабильнее.

В файле конфигурации могут быть отображены мои данные(user/group/pass), т.к. мой сервер работает в рамках локальной сети, без выхода во внешнюю сеть.

ВАЖНО: при генерации лицензионного ключа, необходимо будет скопировать данные файла "iourc" в txt файл на стороне клиента. И добавить в программу GNS3 через вкладку IOS on UNIX preferences.



## Что внутри
- `setup.sh` — автоматическая установка сервера, настройка службы и пароля.
- `gns3-server.service` — шаблон службы systemd.
- `generate_license.py` — исправленный скрипт генерации лицензии `iourc` (без ошибки `struct.error`).
